## Moxfield export converter

A small script to convert a Magic the Gathering decklist from [Moxfield](https://moxfield.com) to a CSV to be used for ordering with a specific seller.

## Usage

The arguments are optional. input-file defaults to `moxfield-export.txt`. output-file defaults to `order.csv`

```
ruby convert.rb [-i input-file] [-o output-file]
```
